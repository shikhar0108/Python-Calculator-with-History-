# Python-Calculator-with-History-
Simple basic calculator in Python that performs calculation and saves history
# Python Calculator

This is a simple calculator program made using Python.

# Features
- Perform basic calculations
- Save calculation history
- Show previous history
- Clear history
- Exit option

# Technologies Used
- Python
- File Handling
- Functions

# Example

Enter calculation: 5+3  
Result: 8

Enter calculation: history  
5+3 = 8

# Commands

history → show history  
clear → clear history  
exit → close program
